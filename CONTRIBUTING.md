# Contributing to LlamaNeuro

Thank you for your interest in contributing to LlamaNeuro! This document provides guidelines and instructions for contributing to this project.

## Code of Conduct

Please read and follow our Code of Conduct.

## How to Contribute

There are many ways to contribute to LlamaNeuro:

1. **Report bugs**: Submit issues for any bugs you encounter.
2. **Suggest features**: Submit issues with feature requests or enhancement ideas.
3. **Improve documentation**: Help improve the documentation by fixing typos, clarifying explanations, or adding examples.
4. **Contribute code**: Submit pull requests with bug fixes, features, or improvements.

## Development Setup

### Prerequisites


- Node.js 14 or higher
- npm or yarn
- Git


### Setting Up the Development Environment

1. **Fork the repository** by clicking the "Fork" button on the top-right of the repository page.

2. **Clone your fork**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/llamaneuro.git
   cd llamaneuro
   ```

3. **Set up the upstream remote**:
   ```bash
   git remote add upstream https://github.com/llamasearchai/llamaneuro.git
   ```


4. **Install dependencies**:
   ```bash
   npm install
   ```

5. **Run tests**:
   ```bash
   npm test
   ```


## Pull Request Guidelines

- Pull requests should focus on a single feature or fix.
- Include tests for any new functionality or bug fixes.
- Update documentation to reflect any changes in public API or behavior.
- Follow the existing code style and conventions.
- Keep your pull request up-to-date with the main branch.

## Code Style Guidelines


We follow standard JavaScript conventions:

- Use ESLint for linting.
- Use Prettier for code formatting.
- Write JSDoc comments for functions and classes.
- Follow the [Airbnb JavaScript Style Guide](https://github.com/airbnb/javascript).
